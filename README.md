# Note App

A simple full-stack note-taking application built with Node.js, Express, and MongoDB.

## Features

* User registration
* User login
* Session-based authentication
* Protected note routes
* Create, read, update, and delete notes
* MongoDB database

## Technologies

* Node.js
* Express
* MongoDB
* HTML
* CSS
* JavaScript

## Running locally

1. Install dependencies:

```bash
npm install
```

2. Create a `.env` file and add the required environment variables.

3. Start the server:

```bash
npm start
```

4. Open:

```
http://localhost:3000
```

## Security

Secrets and environment variables are stored in `.env` and are not committed to GitHub.
